# Security Policy

## Supported Versions

Actualmente, solo la última versión desplegada en `main` recibe soporte activo.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

Si descubres una vulnerabilidad de seguridad en este proyecto, por favor **NO** abras un issue público.

En su lugar, envía un correo electrónico a **alvaro@lvrpiz.com** con los detalles.

*   Incluye pasos para reproducir la vulnerabilidad.
*   Describe el impacto potencial.

Nos comprometemos a revisar y responder a los reportes de seguridad en un plazo de 48 horas.
